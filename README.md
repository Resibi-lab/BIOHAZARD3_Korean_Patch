BIOHAZARD 3 (Steam) 한글 패치
=============================
버전: v1.0.17 (2026-11-03)

대상
- Steam판 BIOHAZARD 3 (앱 4249120)의 일본어판 본편(Bio3_PC.exe)과
  머시너리즈(Bio3_PC_Mercenaries.exe)
- 게임 파일은 들어 있지 않습니다. 게임 데이터(Rofs*.dat)는 디스크에서 바꾸지
  않고, 게임이 실행될 때 한글 패치 로더가 메모리에서 바꿉니다.

설치
1. 게임과 런처를 끕니다.
2. BIOHAZARD3_Korean_Patch.exe 를 실행하고 1(설치)을 고릅니다.
   - 게임 폴더는 자동으로 찾습니다. 못 찾으면 경로를 물어봅니다.
     (설치 파일을 게임 폴더에 넣고 실행해도 됩니다.)
3. Steam에서 게임을 실행하고, 런처의 Language(언어) 목록에서 한국어를 고른 뒤
   스토리 또는 머시너리즈를 시작합니다.

새 버전으로 업데이트
- 이전 버전을 지우지 않고 새 BIOHAZARD3_Korean_Patch.exe 로 설치하면 됩니다.

제거
- BIOHAZARD3_Korean_Patch.exe 를 실행하고 2(제거)를 고릅니다.
  원본 파일은 게임 폴더의 KoreanPatchBackup 폴더에 보관되어 있다가
  제거할 때 제자리로 돌아갑니다.
- Steam의 "게임 파일 무결성 확인"을 하면 런처와 실행 파일이 원본으로 바뀝니다.
  그 뒤 다시 쓰려면 설치를 한 번 더 하면 됩니다.

설치가 "원본과 다름"이라며 멈출 때
- 게임이 업데이트되었거나 다른 모드가 같은 파일을 바꾼 경우입니다.
  Steam 라이브러리 > BIOHAZARD 3 > 속성 > 설치된 파일 >
  "게임 파일 무결성 확인"을 한 뒤 다시 설치하세요.

알아 둘 점
- 런처에 한국어 항목이 추가됩니다. 한국어와 japanese는 모두 한글 패치가
  적용된 japanese 폴더의 게임을 실행하며, 같은 세이브를 사용합니다.
- english 등 나머지 언어 항목은 기존과 동일하게 실행됩니다.
- 세이브 파일은 그대로이므로 패치 전의 세이브도 이어서 할 수 있습니다.
- japanese 폴더에 korean.dll(한글 패치 로더)과 korean_*.bin, korean_text.txt
  가 들어가고, 실행 파일 두 개(Bio3_PC.exe, Bio3_PC_Mercenaries.exe)는
  korean.dll 을 불러오도록 이름 한 곳만 바뀝니다.
- v1.0.14 이전에는 로더가 version.dll 이었습니다. 새 버전을 설치하거나 제거하면
  한글 패치의 옛 version.dll 은 지워지고, 그 전에 있던 다른 모드의 version.dll 은
  제자리로 돌아갑니다.
- 스팀덱(Linux, Proton)에서도 로더가 불러와지도록 했습니다.
  (옛 version.dll 로더는 Proton이 자기 version.dll 을 먼저 써서 불러오지 못했습니다.)
- 게임 안 설정 창(Biohazard3 Setup)도 한글로 나옵니다.
- 게임 그래픽으로 진행되는 이벤트 장면은 동영상처럼 M(맵) 키로만 건너뜁니다.
  원래는 C(결정) 키로 건너뛰어져서 대화를 넘기다 장면을 놓치기 쉬웠습니다.
